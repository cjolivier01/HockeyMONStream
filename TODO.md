## GUI
We shouldnt always open up tabs for "cam 1, cam 2, cam 3". we should only open a cam tab after we have established that the camera exists. For example, if our input video is already a stitched panorama,l we wont have any "cam x" tabs, since we arent doing any stitching. When adding/uploading videos, if we specify which cam, then we expect that cam tab to appear. If we selcted "parnorama" as the uploaded video, for example, then we expect no cam tabs, viodeo starts with the stitched or panorama tab.
