# Highlight editor validation

Validated on x86_64 with an RTX 5090 and DeepStream 9.1.

- Full tree: `HSTREAM_TENSORRT_SDK_ROOT=/home/colivier/.cache/hstream/player-sdk/trt10.16/usr bazelisk build --config=opt --config=blackwell --cpu=k8 //...` passes. This host has TensorRT 11 system headers while DeepStream loads TensorRT 10; the matching installed SDK is required for the existing detector builder.
- `bazelisk test --config=opt --config=blackwell --cpu=k8 //src/apps/hstream-ui/... //src/apps/apps-common/... //src/apps/hstream-ui:highlight_item_editor_interaction_test` passes all 41 tests with the same SDK setting and an X11 display. The modified model/editor tests and the GPU dialog export test were rerun after the final persistence changes.
- `QT_QPA_PLATFORM=xcb bazel-bin/src/apps/hstream-ui/highlight_reel_pipeline_test` passes. It decodes the exported file independently to check a timed box, expiration, clip/card order, a 4.45-second mixed timeline, increasing packet timestamps, silent card audio, delayed MP4 audio, ten-bit HEVC output from a silent source, cards without an archive, cancellation, GPU frame inspection, window resizing and preview looping. FFmpeg generates test fixtures and acts as the independent decoder; production rendering/export never invokes it.
- `bazelisk build --config=jetson //src/libs/highlights:texture_blend` passes with the local Jetson sysroot. The full CLI cross-build cannot analyze the existing `@onnxruntime_linux_jetson` repository because its BUILD file is missing. The desktop targets remain incompatible with Jetson, matching the existing Qt UI boundary.
- `bazelisk build --config=opt --config=arm64 //src/libs/highlights:texture_blend` passes on this x86 host. This checks the SBSA configuration only, not native ARM64 execution. No native SBSA host was available. `ssh -o BatchMode=yes -o ConnectTimeout=5 stubby uname -m` failed with “No route to host,” so Jetson runtime checks were unavailable.

Tracked cues require the author to verify the recorded run/archive association and geometry mode because legacy publication sidecars have no telemetry run identity. Saved observations are scoped to a single source, geometry, seek and reset segment. Tests cover Program rotation/crop conversion, duplicate IDs in separate seek segments, missing observations, and immutable source times through card insertion and trims. A recorded bounding box does not establish a hand position; manual keyframes provide those corrections.

Review round 1 found three issues: wide archives stretched authored artwork, inspecting an empty movement draft blocked the first keyframe, and rotated track click bounds missed visible corners. The renderer now uses the output aspect for cue textures and fits card layouts uniformly; inspection omits an incomplete draft without relaxing saved-plan validation; click bounds include all four transformed corners. Regression checks cover wide/portrait logo proportions, cue typography, empty-draft inspection and strict saves, and a rotated shoulder click. Native export also checks a square logo's placement and dimensions on a 1280×320 panorama card. Independent media probes passed long-GOP inspection, delayed audio, an AAC timestamp gap and a short clip from an 8K Program recording.

Review round 2 found a stale inspection-frame/track-box time mismatch and delayed MP4 audio being placed early. Positioning now requires a successfully held frame at the requested time, and track clicks require the cue-start frame used for the query. Decoded video/audio timestamps use segment stream time before trimming; audio beyond the clip end leaves silence. Video frame intervals are clipped at both ends, discarding sub-microsecond rounding tails that would duplicate hardware encoder timestamps. The X11-only `highlight_item_editor_interaction_test` uses deterministic crossing-player fixtures to check stale frames, changed times, matching clicks and Stop without needing GPU decoding. Run it explicitly with the same Bazel configuration; it has the `manual` tag. Native GPU integration additionally exports both a silent interval before an MP4's delayed AAC start and an audible interval within that stream.

Review round 3 found that a missed player click left the previous track selected, accumulated truncated card frame steps emitted an extra frame at exact second boundaries, and the previous AAC encoder delayed sound by 33.333 ms and lost the reel tail. Track hit tests now clear the selection first, and card timestamps derive directly from frame index and rational rate. AAC uses the native `avenc_aac` element with EOS draining; completed MP4 edit metadata accounts for priming while retaining encoded preroll. Tests check failed retargeting, increasing video PTS/DTS across a one-second 30 fps card/clip join, audio transient alignment within 2 ms, a tone near the final cutoff, and first-cut decoder overlap state. Metadata checks cover 32/64-bit edits, extended media boxes, unchanged video/payload bytes and rejection without mutation of malformed or unexpected layouts. `bash -n scripts/make_deb.sh` validates the added desktop libav plugin dependency.
