Download and installation

Run the sports video pipeline on your GPU

Choose a packaged release or build from source. HockeyMONStream has no subscription fee, but it depends on NVIDIA’s GPU driver, CUDA, and DeepStream components.

Open the latest release Build from source
Before downloading: this is a technical, self-hosted project—not a hosted video service. You provide compatible cameras or recordings, NVIDIA hardware, storage, and the NVIDIA software dependencies.

Verify every download before installing

Each packaged HockeyMONStream application release includes SHA256SUMS. Download it with the files for your platform and verify those files before opening an installer, making a script executable, or running a package command.

On Ubuntu, Jetson, or an existing WSL environment, run:

sha256sum -c SHA256SUMS --ignore-missing

On Windows, open PowerShell in the download directory and run:

Get-FileHash .\hstream_vX.Y.Z_windows-wsl-setup.exe -Algorithm SHA256

Compare the PowerShell result with the matching line in SHA256SUMS. DeepStream comes separately from NVIDIA and is not covered by the HockeyMONStream checksum file; obtain it from an official NVIDIA download page and follow NVIDIA's published checksum or signature verification guidance before giving its package to an installer.

Windows 11

Download and verify the release asset ending in _windows-wsl-setup.exe, then open it. The bootstrapper creates a dedicated Ubuntu environment under WSL 2 and installs the matching HockeyMONStream Debian package.

You will need Windows 11 with virtualization and WSL 2 support, an NVIDIA GPU with a current Windows driver that exposes CUDA to WSL, and the NVIDIA DeepStream 9.1 Debian package. The installer asks you to select the DeepStream package; it is not redistributed inside the installer.

The current public installer is signed with a private/self-signed publisher certificate. Windows therefore shows an unknown-publisher warning unless that certificate is already trusted. Read the complete Windows WSL installer documentation for the security model, files, and uninstall behavior.

Ubuntu desktop

Download three files: the _ubuntu24.04_amd64.deb or _ubuntu26.04_amd64.deb asset that exactly matches the host, install-hstream-deb.sh from the same HockeyMONStream release, and NVIDIA’s separately obtained DeepStream 9.1 Debian package.

After verifying all three downloads as described above, run the helper with the downloaded paths:

chmod +x ./install-hstream-deb.sh
sudo ./install-hstream-deb.sh \
  --deepstream-deb=/path/to/deepstream-9.1_9.1.0-1_amd64.deb \
  --hstream-deb=./hstream_vX.Y.Z_ubuntu24.04_amd64.deb

Use the actual release version and switch ubuntu24.04 to ubuntu26.04 on an Ubuntu 26.04 host. The helper validates package metadata, configures the NVIDIA repositories, and applies the required Ubuntu 26.04 compatibility handling. Do not install a package built for the other Ubuntu release.

NVIDIA Jetson

For JetPack 6-class Jetson systems with DeepStream 7.1, download and verify the release asset ending in _jetson-ubuntu22.04_arm64.deb, then install it through APT:

sudo apt install ./hstream_vX.Y.Z_jetson-ubuntu22.04_arm64.deb

The release also contains a Hugin build script and corresponding source archives used for the Jetson calibration toolchain.

Prepare camera footage

By default, games live under $HOME/Videos/<game_id>. Put each camera’s clips in a separate directory:

$HOME/Videos/game-001/cam1/*.mp4
$HOME/Videos/game-001/cam2/*.mp4

GoPro and Insta360 chapter naming patterns are supported. See the README build guide for source builds and the current run commands.

What happens on the first run

The runner loads the bundled baseline configuration, downloads configured pretrained runtime model assets if they are missing, configures stitching from your footage, and starts the main detection and play-tracking pipeline. You can keep the default game and output roots or configure explicit paths.
