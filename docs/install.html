Download and installation

Run the sports video pipeline on your GPU

Choose a packaged release or build from source. HockeyMONStream is free software, but it depends on NVIDIA’s GPU driver, CUDA, and DeepStream components.

Open the latest release Build from source
Before downloading: this is a technical, self-hosted project—not a hosted video service. You provide compatible cameras or recordings, NVIDIA hardware, storage, and the NVIDIA software dependencies.

Windows 11

Download the release asset ending in _windows-wsl-setup.exe. The bootstrapper creates a dedicated Ubuntu environment under WSL 2 and installs the matching HockeyMONStream Debian package.

You will need Windows 11 with virtualization and WSL 2 support, an NVIDIA GPU with a current Windows driver that exposes CUDA to WSL, and the supported NVIDIA DeepStream Debian package. The installer asks you to select the DeepStream package; it is not redistributed inside the installer.

The current public installer is signed with a private/self-signed publisher certificate. Windows therefore shows an unknown-publisher warning unless that certificate is already trusted. Read the complete Windows WSL installer documentation for the security model, files, and uninstall behavior.

Ubuntu desktop

Download the _ubuntu24.04_amd64.deb or _ubuntu26.04_amd64.deb asset that exactly matches the host release. Install the matching NVIDIA driver/CUDA and supported DeepStream package first, then install the HockeyMONStream package and its dependencies.

The release filename and package metadata identify the intended Ubuntu version. Do not install the Ubuntu 24.04 package on 26.04, or vice versa.

NVIDIA Jetson

For JetPack 6-class Jetson systems, download the release asset ending in _jetson-ubuntu22.04_arm64.deb. The release also contains a Hugin build script and corresponding source archives used for the Jetson calibration toolchain.

Verify the download

Every packaged release includes SHA256SUMS. Download that file from the same release and compare the package hash before installing:

sha256sum -c SHA256SUMS --ignore-missing

Prepare camera footage

By default, games live under $HOME/Videos/<game_id>. Put each camera’s clips in a separate directory:

$HOME/Videos/game-001/cam1/*.mp4
$HOME/Videos/game-001/cam2/*.mp4

GoPro and Insta360 chapter naming patterns are supported. See the README build guide for source builds and the current run commands.

What happens on the first run

The runner loads the bundled baseline configuration, downloads configured pretrained runtime model assets if they are missing, configures stitching from your footage, and starts the main detection and play-tracking pipeline. You can keep the default game and output roots or configure explicit paths.
